{% comment %} WAMA — Barre d'actions globales de la file (zone centrale → dispo en mode simple, sans volets). Chaque app fournit ses ids (les handlers JS de l'app y sont attachés). Variables : start_id — id du bouton « Démarrer tout » (REQUIS) clear_id — id du bouton « Tout effacer » (REQUIS) download_id — id du bouton « Télécharger tout » (si show_download) show_download — (bool) afficher le bouton de téléchargement global download_url — (option) si fourni : rend un LIEN direct (ZIP serveur) au lieu d'un bouton désactivé piloté par le JS de l'app start_url, clear_url — (option) URL des routes `start_all` / `clear_all`. Si fournies, `queue-actions.js` câble le bouton LUI-MÊME (POST + rechargement, avec confirmation pour l'effacement) : l'app n'écrit plus de handler. start_label, clear_label, download_label — libellés (défauts ci-dessous) ⚠ Les trois boutons de cette barre ont longtemps été DÉCORATIFS chez plusieurs apps : les ids étaient passés, aucun JS ne les écoutait (constat écrit dans `imager/index.html:96`). Les `*_url` ci-dessus existent pour que ce cas ne puisse plus se produire — un bouton dont l'URL est déclarée est câblé par la brique, sans une ligne d'app. Une app qui garde son handler par id ne passe simplement pas d'URL (sinon le POST partirait DEUX fois).
