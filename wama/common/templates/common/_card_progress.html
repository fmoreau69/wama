{% comment %} WAMA — Bloc « statut + progression » commun à toutes les cards de file. Badge de statut coloré + barre de progression + % + ETA (rempli par wama-eta.js) + temps écoulé affiché une fois terminé. Variables : status — 'PENDING' | 'RUNNING' | 'SUCCESS' | 'FAILURE' progress — 0–100 elapsed — (optionnel) durée de traitement formatée, affichée sur SUCCESS no_bar — (optionnel) rend TOUT sauf la barre (badge, %, ETA, durée) bar_only — (optionnel) rend UNIQUEMENT la barre Pourquoi ces deux modes : dans la card v3 (CARD_DESIGN §11), l'état vit dans SA section — une colonne étroite — tandis que la barre traverse la card sur toute sa largeur. Rendre le bloc entier en pleine largeur emportait le badge et l'ETA en bas de card, loin de la section ÉTAT. Deux appels au même partial valent mieux qu'un second partial qui dériverait. Sans ces variables, le comportement est INCHANGÉ (bloc complet) pour toutes les apps. Usage : {% include 'common/_card_progress.html' with status=obj.status progress=obj.progress elapsed=obj.processing_display %} {% endcomment %} {% if not bar_only %}{{ status }}{% endif %} {% if not no_bar %}
