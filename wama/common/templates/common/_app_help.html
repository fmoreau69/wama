Les gestes communs
{% endif %}
  • Déposer : glissez vos fichiers sur la card d'entrée (ou cliquez pour parcourir).
  • Régler : le volet droit porte vos réglages par défaut ; la modale ⚙ de chaque élément permet l'édition fine avant lancement.
  • Lancer : ▶ sur l'élément, ou « Tout lancer » dans la barre de file. La progression et l'ETA s'affichent sur chaque card.
  • Récupérer : ⬇ télécharge le résultat ; ⧉ duplique un élément avec ses réglages ; 🗑 supprime.
  • Inspecter : cliquez une card pour ouvrir l'aperçu et les détails dans le volet droit ; le menu « … » porte les autres gestes (partager, envoyer vers une autre app…).
    • {% if help.has_batch %}
  • Lots : un fichier de liste (txt/csv) crée un lot ; sa ⚙ règle toutes ses cards, et son menu « … » les réaligne sur sa référence — celui d'une card fait de ses réglages la référence du lot.
    • {% endif %} {% if help.has_url_import %}

    • {% endif %}
