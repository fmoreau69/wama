Zoom — une carte graphique pour tous

24 Go de mémoire graphique à partager

Un gouverneur

Un seul point d'entrée pour la mémoire graphique : plafond, registre partagé, priorités. Il est né d'un dépassement à 38 Go, le 29/07.

Un modèle reste prêt

Le travailleur GPU garde le modèle chargé pour la tâche suivante ; le choix d'un modèle préfère celui qui est déjà en mémoire.

Ce qu'on a appris

Des modèles différents qui cohabitent se gênent : un essai isolé ne le montre pas, une file mélangée oui (campagne du 02/10).

Matériel actuel : une RTX 4090. À venir : CPU et RAM au même gouverneur, plusieurs cartes. ⏳

Zoom — mémoire et pipelines

Se souvenir, enchaîner

Mémoire et RAG

Postgres + pgvector (bge-m3). Des niveaux : université, labo, équipe, utilisateur, projets. Un contenu y entre par un geste, jamais par un balayage.

Pipelines

Une card porte un pipeline : entrées, étapes, sorties. Le Studio en est l'éditeur en graphe ; une étape périmée seule se recalcule. 🔄
