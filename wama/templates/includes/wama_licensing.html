Un logiciel d'agent public, deux titulaires

L'université

Les droits d'exploitation : reproduire, adapter, distribuer. C'est elle qui choisit la licence et qui signe un dépôt.

Code de la propriété intellectuelle, L113-9

L'auteur

La paternité : être nommé comme auteur, toujours. Elle ne se cède pas et ne dépend d'aucune licence.

droit moral, L121-1 et L121-7

Les deux

L'intéressement : si le logiciel rapporte, l'auteur en reçoit une part fixée par les textes, même après son départ.

Code de la recherche, D532-2 à D532-6

Si l'établissement décide de ne pas valoriser, l'auteur peut en disposer, par une convention avec lui.

02 — La licence de WAMA

AGPL-3.0 : partager, pas interdire

L'AGPL autorise l'usage commercial. Elle oblige celui qui modifie WAMA et le distribue, ou l'offre en service, à publier ses sources sous la même licence.

Zoom — et une exploitation commerciale ?

L'AGPL ne ferme pas la porte

Double licence

Le titulaire n'est pas lié par sa propre licence : il peut concéder le même code sous une licence propriétaire.

À remplacer

Les composants AGPL d'autrui, ou acheter leur licence commerciale ; et les modèles non commerciaux.

Un seul titulaire

Changer de licence reste possible tant que le code a un seul auteur. Une contribution externe demande un accord de contribution.

Ce que l'AGPL n'empêche pas : qu'un tiers offre WAMA en service, sources publiées.

03 — Le non-commercial

Il borne les résultats, pas la recherche

Une licence non commerciale ne gêne pas le travail du laboratoire. Elle limite ce qu'on fait des résultats, et elle ne se mélange pas à l'AGPL dans un même code.

Zoom — passer WAMA en Creative Commons NC ?

Quatre obstacles, aucun gain

Pas faite pour le logiciel

Creative Commons déconseille ses licences pour du code : rien sur les sources, rien sur les brevets.

Incompatible avec l'AGPL

Une clause non commerciale est une restriction ajoutée : il faudrait retirer les composants AGPL.

Ni libre, ni open source

Hors de la liste des licences prévues pour le code des administrations, hors science ouverte.

Rien de plus pour le titulaire

Il peut déjà vendre une licence ; l'AGPL empêche déjà qu'un tiers referme le code.

Zoom — déposer l'idée ?

Une idée ne se dépose pas, son expression oui

L'expression

Le droit d'auteur protège le code, les documents de conception, l'interface. Il naît sans formalité.

La date

Elle se prouve : un dépôt public horodaté, une enveloppe Soleau.

Le nom

Il se dépose comme marque, au nom de l'établissement, après une recherche d'antériorité.

La publication

Publier la vision crée l'art antérieur : personne ne peut ensuite se l'approprier.
