{% comment %} Pourquoi ceci ET le token API — la distinction n'est pas évidente, et Fabien l'a posée le 22/08. Le token authentifie UN CLIENT qui n'agit que pour vous (votre script). Le bot, lui, est UN SEUL programme partagé par TOUT le laboratoire : il doit distinguer qui lui écrit, parmi N personnes. Un token ne peut pas jouer ce rôle sans que chacun colle son secret permanent dans une messagerie. {% endcomment %}

Le bot est partagé par tout le laboratoire : l'appariement lui permet de savoir que c'est bien vous qui écrivez, sans que vous ayez à lui confier votre token. Le code est temporaire et à usage unique — c'est ce qui le rend inoffensif s'il traîne dans une conversation.
