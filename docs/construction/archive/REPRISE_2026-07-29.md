## PIÈGES DE CETTE SESSION (chèrement acquis)

- **JAMAIS de charge GPU sous WSL2 sur ce poste.** 3 crashs hôte le 27/07 en chargeant LocateAnything
  (bug ouvert MS WSL #40732 : pression d'allocation CUDA → kernel panic Hyper-V). Vaut aussi pour
  `manage.py shell` en WSL2 : `django.setup()` importe `torch.cuda` et le process meurt en silence.
  Interroger la base en **`psql` direct**.
- **JAMAIS de pane Leaflet personnalisé** sur la mini-carte : elle est pivotée (`setBearing`) et le
  plugin de rotation ne transforme que les panes standard → la géométrie DISPARAÎT. Utiliser
  `bringToBack()`/`bringToFront()`.
- **Ne jamais éditer ce JS par script/regex** : une injection automatique a produit une double virgule
  (page entière cassée). Édition ciblée + `scripts/check_js.sh` systématique.
- **Migrations NON versionnées** dans ce projet (`.gitignore:8`, seul `__init__.py` suivi). Ne pas
  forcer leur ajout.
- **`wsl --shutdown` arrête Postgres WSL2** et il ne redémarre pas seul (`sudo` demande un mot de passe) :
  le faire relancer par Fabien via son script de démarrage habituel.
- **Deux sessions homonymes** : `ENA_CASA_..._seg` = analyse COMPLÈTE (0 → 8 382 s, zéro trou) ;
  `_det`/`_det_save` = restreintes aux intersections (75 % de la timeline sans données, par conception
  du profil). Le profil complet s'appelle trompeusement `Intersections_yolo26s-segment` —
  **suggestion : le renommer `Complet_yolo26s-segment`**.
- **gunicorn cache les templates** (HUP après modif) ; JS modifié → copier vers `staticfiles/`.
