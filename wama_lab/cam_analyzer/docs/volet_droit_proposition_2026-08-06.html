Ce que montre l'exploration

Le volet est fait de 3 cartes de cadre (média / réglages / actions) plus un calque flottant. Chaque carte mélange aujourd'hui plusieurs intentions :

🗺 Carte & passages 4 intentions mêlées

Configuration (panneau #calibPanel caché sous « Ouvrir » : synchro GPS, yaw, FOV, antenne, hauteur caméra, sol, recalage ortho, trajectoire) · Affichage (VUE 360° / Prédiction / Garés / Voie·vidéo, filtres Conf & Voie, Live) · Calcul (#predictionCalcBtn « Indicateurs ») · Comparaison (#featModesBtn « Comparer ») — le tout au-dessus de la mini-carte.

🎬 Profil actif 2 intentions

Lecture du profil + Lancer une analyse : le vrai foyer du calcul — « Détection + SAM3 », le PIPELINE par passes (avec ▶ de rejeu), « Compléter », « Tout relancer », couverture. La place naturelle de tout ce qui calcule.

⬇ Exports cohérent

Détections / Rapport / Segments / Conflits. Une seule intention : sortir les résultats. À garder.

⚑ Modes flotte sur la carte

#featModesPanel est en position:absolute par-dessus la mini-carte (14 bascules ⚑, dont celles marquées ⟳ qui exigent un recalcul). Ouvert par le bouton étiqueté « Comparer ». Déconnecté du pipeline qu'il gouverne pourtant.

Le principe directeur

Tout ce qui calcule est une passe du pipeline. La carte n'affiche que. La configuration se pose une fois, à part.

C'est exactement la logique déjà appliquée à la profondeur (étage 1 compute_depth_task → étage 2 compute_depth_calc_task, deux passes dans le pipeline). On l'étend à tout le volet : « Indicateurs » est un calcul → il devient une passe, il quitte la carte. Le pipeline peut contenir analyse et calculs sans souci — c'est même le but ; ce qui gêne, c'est un calcul hors pipeline, égaré parmi les boutons d'affichage.

Diagnostic — 6 incohérences

1

« Indicateurs » : un calcul égaré dans la carte d'affichage

#predictionCalcBtn calcule TTC/PET + tracking 360°, mais siège dans le groupe « Analyse » de la carte, à côté des bascules de vue. C'est le point que tu as nommé.

2

Le démarrage du calcul est éparpillé sur 3 endroits

« Lancer une analyse » (3 boutons), le PIPELINE (▶ par passe + Compléter / Tout relancer), et « Indicateurs » dans l'autre carte. Trois entrées pour une même intention.

3

« Comparer » ouvre en fait le panneau ⚑ Modes

Le bouton étiqueté « Comparer » (#featModesBtn) déplie les 14 bascules. Étiquette ≠ effet ; et l'A/B objectif se perd dans un menu de réglages.

4

La calibration — l'étape 0 — est cachée sous un « Ouvrir »

Elle conditionne toute la projection sol (donc tout l'aval), mais elle est enfouie dans un repli de la carte plutôt que posée comme préalable clair.

5

Les ⚑ Modes flottent sur la carte, loin du pipeline qu'ils gouvernent

Changer une bascule ⟳ devrait rendre des passes « périmées ». Aujourd'hui le lien est invisible : l'overlay est ailleurs, le pipeline ne réagit pas visuellement.

6

« Indicateurs » alerte mais n'affiche aucun chiffre

Le calcul le plus « lisible » (TTC/PET, insertions) ne restitue pas ses nombres dans le volet — alors que la carte Exports est l'endroit tout trouvé.

Proposition — 4 zones, 4 verbes

Un ordre lu de haut en bas comme un mode d'emploi : je configure, je lance, je regarde, je sors les résultats. Aucune reconstruction lourde — on redistribue les blocs existants dans les 3 cartes de cadre, on dé-flotte les Modes, on promeut une passe.

① CONFIGURER

Poser la géométrie & les options

  • Profil actif + Modifier
  • Calibration (synchro, yaw, FOV, antenne, H cam, sol, recalage ortho, trajectoire) — dépliée, plus enterrée
  • ⚑ Modes dé-flotté — docké ici, scindé Affichage vs ⟳ Recalcul via le champ scope déjà présent
② ANALYSER

Ce qui calcule = le pipeline, source unique

  • Boutons Lancer (Détection+SAM3, Compléter, Tout relancer) en tête du pipeline
  • Le PIPELINE — dont Indicateurs passe promue, aux côtés de Profondeur + Calculs profondeur
  • Couverture d'analyse
③ AFFICHER

La carte — zéro calcul

  • Mini-carte
  • VUE : 360° / Prédiction / Garés / Voie·vidéo
  • Filtres Conf ≥, Voie ; curseur Live
  • Comparer renommé — bascule A/B d'affichage (lit les variantes stockées)
④ LIRE

Sortir les résultats

  • Exports : Détections / Rapport / Segments / Conflits (inchangé)
  • + Lecture des indicateurs nouveau — les chiffres que la passe Indicateurs produit

Décisions à trancher avant de coder

Q1« Indicateurs » → vraie passe indicators ?

La déclarer dans PassType + pass_tracking.order (comme depth_calc) la fait apparaître dans le pipeline avec statut/rejeu, et supprime le bouton égaré. C'est le geste central.

▸ Recommandé — cohérent avec le travail profondeur déjà fait.

Q2Scinder visuellement le pipeline Analyse / Calculs ?

Un champ stage sur PassType (analyse | calcul) permettrait deux sous-titres dans la liste. Purement cosmétique — le pipeline reste une seule séquence.

▸ Optionnel — utile si la liste s'allonge (déjà 15 passes).

Q3Dé-flotter ⚑ Modes vers ① et scinder par scope ?

Les bascules ⟳ (scope='compute') marquent des passes « périmées » ; les autres (scope='live') n'affectent que l'affichage. Le champ existe déjà dans features.py — le split est déclaratif.

▸ Recommandé — supprime l'overlay sur carte (incohérence 5) sans code neuf côté flags.

Q4Lecture des indicateurs dans ④ maintenant ou plus tard ?

Afficher TTC/PET + insertions sous les Exports. Dépend de Q1 (la passe doit d'abord produire un résumé lisible).
